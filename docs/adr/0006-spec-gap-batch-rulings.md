# ADR-0006：SPEC-GAP 批量裁决（RS-001..010/012/013）

日期：2026-09-27 · 状态：已接受 · 关联：ADR-0005（RS-011）

## 背景

第四、五套独立实现（lang-rs/lang-cs）开发期间登记的 spec 歧义与文档漂移累计 13 条。
本 ADR 一次性裁定，消除第六套实现或契约演进前的悬案面。逐条裁定同时写入对应 spec 正文
（标记 v1.0.1 / ADR-0006），台账状态同步关闭。

## 裁决

| 条目 | 主题 | 裁决 |
|---|---|---|
| RS-001 | 嵌套字符串转义跨后端分歧 | **逐后端口径**：→Go 沿 strconv.Quote 惯例、→JS 沿 JSON.stringify 惯例、解释器与 →Go 一致；spec 标注平台差异例外，语料避开分歧码点 |
| RS-002 | jsonStringify 浮点 | **TS interp 为契约源**：定点段 [1e-6,1e21)、e 形负指数无前导零、-0.0 → `0`；→JS prelude 的历史偏差不回改（平台差异例外） |
| RS-003 | 非字符串映射键 JSON | **统一运行时错误**（RUNTIME-JSON-001），消息形 `JSON 对象键须为 string，得到 <类型>`；各实现同步 |
| RS-004 | 顶层 `chan` 保留字 | **维持证据行为**：顶层语句位 E1001 系拒绝，仅类型注解位可用；spec 补明文 |
| RS-005 | Arm/EnumCase span | **spec 明文全部 AST 节点列级**（含臂/case/参数）；rust/cs 已符合；旧实现 dump 不强制回改 |
| RS-006 | int(float) 越界/NaN | **NaN → 0；溢出饱和到 int64 边界；其余向零截断**（Rust `as` 语义，全实现可一致落地）；spec 明文 + 各实现同步 |
| RS-007 | float NaN 比较 | **IEEE**：任何比较 false（`!=` 恒 true）；spec 明文 + 各实现单测锁定 |
| RS-008 | conformance README「14 类」 | 文档漂移，改为实测 16 类 |
| RS-009 | YAML 锚点 | README 已声明拒绝锚点——**已符合**，关闭；rust 侧解析器宽容度记录在案 |
| RS-010 | line=0 无位置诊断 | **spec 明文认可**：无位置诊断 line=0、column=1 合法 |
| RS-012 | 块级类型写入层 | **NAME-SCOPE-001 词法作用域为准**；Go/TS/Python checker 已对齐修复（同波），关闭 |
| RS-013 | 用户泛型 struct/enum | **静默容忍**（擦除占位参与检查，不产生诊断）；硬化（补诊断码）留待 v1.x 真实需求 |

## 实施

- 纯条文：RS-001/002/004/005/008/009/010/013（本 ADR + spec 编辑当日落地）。
- 实现同步：RS-003（Go/JS prelude 受控错误）、RS-006（Go/TS/Python 内建 int 换饱和语义；Rust/C# 原生即符合）、RS-007（五实现单测锁定）——同波智能体落地，各实现全套件保持绿。
- RS-011 已由 ADR-0005 关闭；Go/TS checker 对齐已同波落地。

## 遗留候选（不属本批）

表达式语句位置的顶层 `?`（`f()?` 单独成句）：checker 现报 E3005、Go interp 运行时支持。
倾向放行，待与 RS-011 残余面合并裁决（ADR-0005 扩展）。
