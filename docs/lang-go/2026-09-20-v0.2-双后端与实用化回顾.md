## 版本界碑

- **v0.2.0** = `75b25c8`（→JS + check 收口）。之后的补丁串（并发、bind、
  tour、更名）归入 v0.2.x，直到 v0.3.0 Semantic Core 重开主线。
- 三路执行格局在 v0.2.0 形成：**解释器 / →Go / →JS**，同一程序 stdout
  逐字节一致——此后每一版都以它为回归硬门，v0.8 的 conformance 套件
  是它的制度化形态。

## v0.2 已知边界（v0.3 起逐项解决）

- 检查依赖 →JS 转译（没有独立前端）→ v0.3 建 resolver/类型检查器独立前端
- 符号/类型无统一模型，工具（重构/查询）无从谈起 → v0.3 Semantic Core、
  v0.4 Agent Contract、v0.6 Semantic Graph
- 注释在格式化后丢失 → v0.5 Safe Editing 的 Lossless 注释层
