# v1.0.0-rc.1 Freeze 声明

发布日期：2026-09-21。自此声明起，lang-go 进入 **Release Candidate 冻结期**。

## 冻结范围（RC 后不再新增/修改，除非 release blocker）

1. **语言语义全部 12 规则族**（specs/ 11 份主题规范）：词法、文法、名字解析、
   类型系统、泛型、值/引用语义、求值顺序、控制流与模式、Option/Result、模块、
   并发 Task/Channel、运行时失败与输出面。
2. **Rule Catalog**（specs/rules.md）：约 60 条 Rule ID 与 27 个诊断码的映射——
   不可改名、不可复用、不可改义；新增只追加。
3. **Agent Contract schemaVersion 1**：同一 major 内只加 optional 字段；
   破坏性变更 → schemaVersion 2。
4. **SourceSpan 契约**（specs/source-span.md）：0 基码点 offset、1 基行/列，
   Unicode 按码点度量。
5. **Conformance manifest 格式**（specs/conformance README）：向后兼容扩展才可。

## rc.1 时的验证状态

- Conformance：**151 case，Go 参考实现与 typescript 独立实现双侧全绿**。
- N 级 Rule 覆盖 **28/28 COVERED**（specs/rule-coverage.md）。
- 确定性：150+ case × 10 次全管线快照逐字节一致。
- fuzz seed / property / benchmark 基线全部绿（specs/performance.md）。
- 全量 Go 测试 21 包绿；typescript typecheck/build 干净。

回归、文档正确性修复。**禁止新语言 feature、新 Agent feature、大规模重构。**
