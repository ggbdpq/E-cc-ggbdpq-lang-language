## 3. Dogfooding 项目裁定

**langdoc**：lang-go 源码文档提取器——扫描 .lang-go 源目录，解析 fn/struct/enum/
let 声明与注释，输出 JSON/Markdown API 参考文档。理由：
- 真实用途（lang-go 生态自身需要）；天然覆盖 modules（多文件多模块）、struct/enum、
  collections、string 处理（Unicode）、JSON 输出、Result/`?` 错误传播、match、泛型。
- 规模可控地达到 2k LOC / 15 文件 / 5 模块（cli / loader / model / render / report）。
- 全工作流可执行：fmt → check → test → inspect → rename（真实重构）→ verify。
