# 2026-09-25 lang-cs 计划差异（相对 lang-rs 母本）

> 母本未提及的条目一律按母本执行。本文只列 C# 宿主带来的差异。

## 1. 第五实现的对抗轴：UTF-16 码点世界

四套既有宿主全部码点友好（Go/TS/Python 的 string 迭代即码点或语言层已封装；Rust 显式映射层）。
C# 的 `string` 是 **UTF-16 code unit 序列**：astral 码点（emoji、生僻字）= 代理对（2 个 char），
`string.Length`、`s[i]`、`Substring` 全部按 code unit 计。这意味着：

- 任何「拿 char index 当 SourceSpan offset」的写法都将在 astral 输入上静默错位——这正是本语言
  Unicode Span 对抗重点（ASCII/中文/emoji/combining/CRLF/混合）的宿主级放大器；
- `Lang.Core.SourceText` 必须提供 **charIndex ↔ code-point** 映射（对应 lang-rs 的 byte↔cp 层），
  parser 内部可用 char index，出边界前必须折算；emoji 用例必须先红后绿；
- 列级诊断、safe-edit 的 TextEdit 切片、formatter 注释贴附全部走映射层——禁止裸 `Substring`。

**验收增补**（母本 §53 之上追加）：对抗用例矩阵含 🦀/𝕏/𠀀 类 astral 码点的 span、诊断、rename 三层各至少 1 例。

## 2. 宿主技术裁定（Ownership 模板的 C# 预答）

| 决策点 | 裁定 | 理由 |
|---|---|---|
| 值语义 | `readonly record struct` 承载 ID/Position/Span；Value enum 用类层次 + 工厂，禁 struct 递归 | 与 lang-rs「Value::clone 即深拷贝」对齐：C# record 的 with/clone 语义显式化 |
| 引用/别名 | 显式 Place/RefValue 类（照抄 lang-rs 模型），禁用 C# 引用参数 `ref`/`ref struct` 表达语言引用 | 语言别名语义 ≠ 宿主引用语义 |
| 泛型 | lang-go 泛型是**擦除**语义（GEN-*）；C# 泛型是 reified——**禁止用 `List<T>`/泛型方法承载语言泛型**，一律按擦除口径显式实现（TypeObject + 运行时检查）。C# 侧泛型只允许用于编译器实现内部容器 | 镜像母本 §15 对 Rust 单态化的警告 |
| int64 | `long` 原生；算术溢出检查用 `checked`（RUNTIME-ARITH 对齐证据口径后再定） | — |
| 浮点/输出 | float 格式 = strconv.FormatFloat('g',-1) 镜像（lang-rs 的 lang-backend-go fmt 规则层为规范证据）；JSON 面 = RUNTIME-JSON-002 | — |
| 确定性集合 | 禁 `Dictionary`/`HashSet` 迭代序外泄——插入序用 `List`+索引或维护序字典；排序输出显式 sort | 对齐 VALUE-MAP-006 与母本 §34 |
| 字符串所有权 | 不可变 `string` + `Rc` 等价不需要；堆对象arena用 `List<T>` 槽位表 + int 索引 newtype（ValueId 等） | 照抄 lang-rs HeapArena 形态 |
| Task/Channel | 协作式单线程调度器（禁 async/await 进入语义面）；channel 缓冲 1024 | 母本 §25 |
| unsafe | 全解决方案禁用：`Directory.Build.props` 设 `AllowUnsafeBlocks=false` | 对应 forbid(unsafe_code) |
