# 类型系统规范（TYPE / GEN）

## TYPE-KINDS-001 类型类别

`int`（64 位有符号）、`float`（64 位）、`bool`、`string`、`[T]`（数组，引用语义）、`map[K]V`（K ∈ {int,string,bool}，保插入序）、struct（值语义）、enum（含预载 Option/Result）、函数类型 `fn(T...): R`、`chan[T]`、引用 `&T`（仅变量）、区间 `lo..hi`、`any`、`Unknown`、unit `()`。

## TYPE-ASSIGN-001 可赋值性

表达式静态类型 T 可赋给声明类型 U 当且仅当：T 与 U 同一类型；或 U 为 `any`；或 T 为 `Unknown`（保守放行，见 TYPE-ANY-002）。**无隐式数值转换**：int 与 float 混用算术/比较/赋值 → **E3002**。其余不匹配 → **E3001**。

## TYPE-ANY-002 Any 与 Unknown

`any` 是**动态边界**类型（jsonParse 结果、extern 边界）：允许赋给/赋自任意类型，运行时经类型断言收窄，断言失败为运行时错误。`Unknown` 是**推断不出**（无注解且无法推断）的内部状态：保守放行静态检查，不得视为拥有一切能力的逃生口。二者禁止互换语义：新代码不得以 `Unknown` 规避检查。

## TYPE-STRUCT-003 名义类型

struct 与 enum 是**名义类型**：类型身份由声明符号决定，字段完全相同的两个 struct 不兼容。

## TYPE-FN-004 函数类型

函数按签名结构兼容：参数类型与返回类型一致即可赋给同型函数值（函数名不是类型身份）。

## TYPE-CONV-005 显式转换

`int(x)`/`float(x)`/`str(x)` 显式转换；`int` 对不可解析字符串报运行时错误（如 `int("4x")`）。除此之外无任何隐式转换出口。

## TYPE-ANN-006 注解规则

参数与返回类型注解可省略（推断或放行为 Unknown）；→Go/→JS 转译要求**参数必须注解** → **E3007**（参数缺注解）。带 `?` 的函数必须注解返回 `Result[T, error]` → **E3005**。

## TYPE-MEMBER-007 成员访问

字段/方法访问按静态类型解析：struct 字段与方法（值接收者）；不存在 → **E3004**。

## TYPE-INDEX-008 索引与键

索引端点须为 int → **E3013**；映射键须为 int/string/bool → **E3014**；被迭代类型须支持迭代协议 → **E3010**；一元/逻辑运算不适用于该类型 → **E3011**；`&` 仅可作用于变量 → **E3012**。

## GEN-DECL-001 泛型声明

`fn name[T](params)`；类型参数在签名与体内作为类型使用。**擦除语义**：运行时表示统一为动态值（解释器直接动态；→Go 以 `T any` 类型参数 + any 装箱；→JS 天然动态）。用户泛型 struct/enum v0.9 冻结不支持（预载 Option/Result 除外）。

## GEN-INFER-002 泛型推断

调用点从实参静态类型推断类型实参；推断失败或实参不兼容 → **E3001**。泛型函数体内对 T 值仅可做 any 允许的操作（比较/内建/透传），不得假设具体类型运算。

## GEN-SUBST-003 替换一致性

同一泛型函数的不同实例化共享同一份运行时代码（擦除）；Option[T]/Result[T,E] 的 T/E 仅约束静态检查，运行时载荷装箱（→Go `LangGoOpt[T]`/`LangGoRes[T]`，E 仅支持 error → **E3009**）。
