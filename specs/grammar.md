# 语法规范（PARSE）

## PARSE-001 程序结构

程序 = 顶层声明序列：`fn`（含方法）、`struct`、`enum`、`let`/`var`（全局值）、`import`、`extern`。入口为无参 `fn main()`；执行完顶层声明后调用 main，无 main 则按脚本顺序执行顶层语句（仅解释器接受顶层语句，转译目标显式拒绝——见 ADR-0001）。

## PARSE-002 声明

- 函数：`fn name(参数表): 返回类型 { 体 }`；参数与返回类型注解可省略（→Go/→JS 转译要求参数必须注解，见 TYPE-ANN-001）。
- 方法：`fn (r Recv).name(...)` 值接收者，Go 风格，接收者无冒号。
- 泛型函数：`fn name[T](...)`，类型参数跟在名字后。
- struct：字段 `name: 类型` 逐行声明。enum：case 逐行声明，载荷按位置；case 可无载荷。
- 全局绑定：`let`/`var`。

## PARSE-003 语句

| 语句 | 形式 | 语义要点 |
|------|------|----------|
| 绑定 | `let x = e` / `let x: T = e` | 不可重绑 |
| 可变绑定 | `var x = e` | 可重绑 |
| 赋值 | `x = e`、`p.f = e`、`a[i] = e`、`m[k] = v` | 字段与容器内容可变性与绑定可变性解耦 |
| 复合赋值 | `+= -= *= /=` | `+=` 对数组是原位拼接（push 语义，别名可见） |
| 条件 | `if c {} else if c2 {} else {}` | 条件位置禁止裸 struct 字面量（PARSE-006） |
| 循环 | `while c {}`；`for x in iter {}` | 支持 break/continue |
| 返回 | `return` / `return e` | 无值返回 `()`（unit） |
| 表达式语句 | `f(x)` | 求值后丢弃 |
| 并发 | `go <具名函数调用>` | 见 concurrency.md TASK-SPAWN-001；实参在 go 语句处求值 |

## PARSE-004 运算符优先级（低 → 高）

| 级 | 运算符 | 说明 |
|----|--------|------|
| 1 | `\|\|` | 短路（EVAL-SHORTCUT-001） |
| 2 | `&&` | 短路 |
| 3 | `==` `!=` | 标量与 enum 可比；数组/映射/struct 不可比（RUNTIME-EQ-001 运行时错误） |
| 4 | `<` `<=` `>` `>=` | 仅同类型数值/字符串 |
| 5 | `..` | 区间，半开 |
| 6 | `+` `-` `\|` `^` | 数值相加；`string+string` 拼接；`\| ^` 位运算（int） |
| 7 | `*` `/` `%` `&` `<<` `>>` | 除零/模零运行时错误；位运算语义与 Go int64 一致（二进制补码） |
| 8 | 一元 `-` `!` `&` | `&` 仅可作用于变量（前缀位置取引用、中缀位置位与，不冲突） |
| 9 | 后缀 `()` `[]` `.` `?` | 调用、索引/切片、字段、`?` 传播 |

## PARSE-005 match 语法

`match` 是**表达式**。每臂 `模式 => 表达式`，臂间换行分隔（无逗号）。模式四类：通配 `_`、字面量（`==` 语义比较）、绑定（小写标识符，捕获整个值）、构造（大写标识符可带子模式，对应 enum case，载荷按位置解构）。match 可作实参（其分支换行存活）。

## PARSE-006 控制头禁止裸 struct 字面量

if/while/match 头部与 for 迭代器位置禁止裸 struct 字面量（消除 Rust 式 `P{x:1}` 与块起始的歧义）；加括号即可：`if (Point{x:1}).x > 0` 合法。
