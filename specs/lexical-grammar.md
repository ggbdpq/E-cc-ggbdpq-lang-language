# 词法规范（LEX）

源文件为 UTF-8 文本，扩展名 `.lang-go`。语法产出以本文件为唯一真值。

## LEX-001 记号类别

记号 = 关键字 / 保留字 / 标识符 / 整数字面量 / 浮点字面量 / 字符串字面量 / 运算符 / 标点 / 换行 / EOF。空白（空格、制表）分隔记号但不产生记号。

## LEX-002 注释

`//` 起至行尾为行注释；无块注释。注释是 trivia，可出现在任意记号间，不影响语义。

## LEX-003 标识符

Unicode 字母或 `_` 开头，后接 Unicode 字母 / 数字 / `_`。单独的 `_` 是通配符记号（match 通配臂、不占位绑定），不可作为绑定名引用。

## LEX-004 关键字与保留字

关键字（15）：`let var fn return if else while for in match struct enum true false break continue`。
保留字（5）：`go chan import extern interface`。前四个已启用；`interface` 使用即诊断 E1001 系（尚未启用）。

## LEX-005 整数字面量

十进制或十六进制（`0x`/`0X` 前缀）。类型恒为 `int`（64 位有符号）。无科学计数法。

## LEX-006 浮点字面量

含 `.` 的数字串，`.` 后必须为数字（因此 `1..3` 是两个整数夹区间运算符，不是浮点）。类型恒为 `float`（64 位）。

## LEX-007 字符串字面量

双引号定界；转义仅 `\n \t \r \" \\` 五种，其他转义序列为词法错误。字符串不可变；按 Unicode 码点索引与切片，`len()` 返回码点数。

## LEX-008 换行与续行

无分号。**换行即语句结束**。仅当行尾前一记号为：运算符、逗号、冒号、`=>`、`..`、`.`、开括号 `(` `[` `{` 时，该换行被忽略（续行）。因此多行字面量与多行实参表须在行尾留逗号；match 分支之间靠换行分隔，match 作实参时其分支换行同样存活。
