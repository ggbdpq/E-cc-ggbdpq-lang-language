# 名字解析规范（NAME）

## NAME-SCOPE-001 作用域层级

全局（模块合并后的单一顶层命名空间）→ 函数体 → 块（if/while/for/match 臂体）。内层可读外层；块内 `let`/`var` 声明遮蔽外层同名绑定（shadowing 合法，引用按静态作用域解析）。

## NAME-SHADOW-002 遮蔽

内层声明遮蔽外层同名绑定，遮蔽在声明处生效；诊断码不报（合法）。

## NAME-DUP-003 同作用域重复定义

同一作用域内重复定义同名绑定/函数/struct/enum → **E2001**。

## NAME-UNDEF-004 未定义名

引用不存在于任何可见作用域的名字 → **E2002**（含未知 struct、未知构造器）。

## NAME-CTOR-005 构造器唯一性

enum case 名全局唯一（与预载 Some/None/Ok/Err 重名即冲突）→ **E2003**（用户构造器重名）/ **E2006**（case 与内建名冲突）。

## NAME-RECV-006 方法接收者

方法接收者必须是已知 struct → **E2004**。

## NAME-MUT-007 可变性

`let` 绑定不可重新赋值 → **E2005**；`var` 可重绑。字段与容器内容总是可写（与绑定可变性解耦）。

## NAME-PLACE-008 控制流语句位置

`break`/`continue` 必须在循环体内 → **E2007**；`return` 必须在函数体内 → **E2008**。

## NAME-NEST-009 嵌套类型声明

fn 体内声明 struct/enum 非法 → **E2010**（类型集合须平坦）。

## NAME-MERGE-010 合并命名空间

目录即包：装载器把当前目录全部 `.lang-go`（文件名序）合并为单一顶层命名空间；跨文件同名符号按 NAME-DUP-003 报错，跨文件引用无须 import 同目录文件（import 仅用于引入子目录/子文件见 modules.md）。
