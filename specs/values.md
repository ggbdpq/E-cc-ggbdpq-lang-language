# 值与内存规范（VALUE）

GC 委托宿主（→Go 用 Go GC，→JS 用引擎 GC）。本文件定义**可观察的值语义**——宿主数据结构（Go map/slice 等）不得反向定义语言语义。

## VALUE-COPY-001 struct 值语义

struct 在绑定、传参、返回时**整体浅拷贝**：顶层字段逐字段复制；字段中的数组/映射/引用保持共享（嵌套 struct 字段递归拷贝）。

## VALUE-SHARE-002 容器引用语义

`[T]`、`map[K]V` 为引用语义：赋值/传参/返回共享底层数据；`push(arr, v)` 原位追加对所有别名可见；`+=` 对数组同 push 语义。字符串不可变（VALUE-IMMUT-005）。

## VALUE-REF-003 引用

`&x` 取变量引用（仅限变量，E3012）；通过引用读写字段/索引即读写原值；无指针算术；引用无生命周期标注（GC 兜底）。

## VALUE-CAPTURE-004 闭包捕获

匿名函数（表达式位置 `fn`）捕获定义处环境**按引用**：捕获的 `var` 在闭包与定义作用域间共享可见；捕获 `let` 绑定则不可变。

## VALUE-IMMUT-005 字符串不可变

字符串一旦构造不可修改；索引赋值非法（运行时错误）；索引/切片产生新字符串。

## VALUE-MAP-006 映射插入序

映射迭代（keys/values/for-in）恒按**插入序**；`jsonStringify` 输出时按键字母序（RUNTIME-JSON-002）。该序为规范行为，任何实现必须保持。

## VALUE-TASKSHARE-007 跨 Task 共享

Task 间仅可通过 channel 传递值；channel 载荷按 VALUE-COPY-001/002 语义复制/共享（struct 拷贝、容器共享）。禁止在 Task 间假设共享可变变量（→Go 真并行下有数据竞争，语言层不提供同步原语——channel 是唯一通信机制）。

## VALUE-UNIT-008 unit

无值返回/表达式语句的结果为 `()`（unit）；unit 仅出现在 return 与语句位置，v0.9 冻结：不支持 unit 类型绑定与 unit 作为参数/元素。

## VALUE-ELEM-009 容器元素的值语义

struct **写入容器**（字面量元素、`push`、索引/字段赋值右侧）与**从容器读出**时按值语义处理：读出的是副本，对副本字段的修改不回写容器，除非显式写回。容器本身（数组/映射）仍为引用共享（VALUE-SHARE-002）。例：`xs[i].f = v` 等价于「读元素副本 → 改字段 → 写回槽位」，不影响同源的其他别名。〔v1.0 审计裁定：统一三路/四路行为，此前 AST 解释器对容器内 struct 为共享指针，属实现偏差〕
